Android Edge
使うもの：Edge＋Tampermonkey。
① Tampermonkeyを有効化 → ② 下の「本人通知URLをコピー」 → ③ Edgeの拡張機能からTampermonkeyのDashboardを開く → ④ Utilities（ユーティリティ）→ URL に貼付 → Import/Install → ⑤ note.comを開く。
Tampermonkeyの中継ページや.user.js直開きは使いません。

iPhone / iPad Safari
参加者向け：Userscriptsを使う手順。
① App StoreからUserscriptsを入れる → ② iPad/iPhoneの設定 ＞ Safari ＞ 拡張機能 ＞ Userscripts をON（可能ならすべてのWebサイトを許可） → ③ Userscriptsアプリを開き、Change / Set Userscripts Directoryで保存先フォルダを1つ決める → ④ 下の「本人通知ファイルをダウンロード」 → ⑤ ファイルAppの「ダウンロード」から、今決めたUserscriptsフォルダへ mumei-note-insight-notification.user.js を移動 → ⑥ Safariでnote.comを開く。
