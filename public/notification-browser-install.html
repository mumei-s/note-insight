INSIGHTをインストール / 更新

本人通知ツール

使っている端末とブラウザのパネルだけ開いて進めます。すでに導入済みなら、拡張機能の入れ直しは不要です。

通知画面は下部固定の4パネル。
「読込 / フィルター ON・OFF / 設定 / INSIGHT」。読込は自動を基本にし、保存済み境界から差分だけを続行します。
文字列画面を開かずに更新する

EdgeのTampermonkeyを開き、「ダッシュボード → インストール済み」で、まず 無名S note INSIGHT 本人通知 の「更新を確認」を実行してください。

更新できない場合は、下のボタンで最新版のスクリプトをコピーできます。ブラウザに文字列を表示する必要はありません。

コピー後：Tampermonkeyで既存の本人通知スクリプトを開き、エディター内を全選択 → 貼り付け → 保存。スクリプトを削除する必要はありません。
通常更新リンク（文字列になる場合は使用しない）
更新状態を自動確認します。
⚠ コードが文字列で表示されて更新できない場合

文字列が開いただけでは更新されません。Edgeの「拡張機能 → Tampermonkey → ダッシュボード → ユーティリティ → URLからインポート」で、下のURLを取り込んで「更新 / インストール」を確定してください。

既存の本人通知スクリプトを更新します。二重インストールや拡張機能の削除は不要です。更新後、ここへ戻って最新版を確認してください。
note公式🔔パネルOFFでも本人通知の読取・保存は継続します。noteの🔔画面に重なる操作パネルだけ非表示にします。
