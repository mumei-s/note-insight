Tampermonkeyをご利用の場合のみ

お使いのブラウザのTampermonkeyを開き、「ダッシュボード → インストール済み」で、まず 無名S note INSIGHT 本人通知 の「更新を確認」を実行してください。

更新できない場合は、下のボタンで最新版のスクリプトをコピーできます。ブラウザに文字列を表示する必要はありません。

コピー後：Tampermonkeyで既存の本人通知スクリプトを開き、エディター内を全選択 → 貼り付け → 保存。スクリプトを削除する必要はありません。
