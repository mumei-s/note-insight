アイコン＋キャプション 貼り付け装置

v1.2.1
記事URL / マガジンURL / #タグを1つの欄へ
全部同じ入力欄に上から並べます。種類は自動判定。記事URL＝その記事のスキした人、マガジンURL＝掲載記事、#タグ＝検索記事です。
上から優先して合算し、「件数指定」なら合計件数に達した時点で終了。「全数」なら並べた全ソースを最後まで読みます。

画像取得を強化
アイコンはスキ一覧・記事API・クリエイターAPIから補完。記事サムネは記事APIに加えてOG画像まで補完します。

貼り付けは全自動
「読み込み→全自動貼付」を1回押すだけで、取得 → 対象決定 → アイコン/サムネ取得 → カード生成 → note画像アップロード → 記事URLリンク設定 → 下書き保存まで進みます。＋ボタンや「画像」は押しません。

後処理
「今回カード一括削除」＝この装置が貼ったカードだけ削除。
「最初に戻る」＝今回カード削除＋入力/件数/記事選択/途中記録を初期化。元本文・元画像は残します。

最後は必ず「実績の算数」を1件追加します。
件数欄はAndroid向け数字入力に修正済み。 タップでカーソルが入り、数字キーボードから直接変更できます。
－で収納、×で極小化、タイトル長押しで移動できます。
INSIGHTとは完全に別ツールです。
