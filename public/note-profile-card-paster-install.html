アイコン＋キャプション 貼り付け装置

v1.0.0
① 記事URL → スキした人
記事URLと件数を指定。各クリエイターから「最初の記事」「固定（なければ最新）」「最新記事」を選択できます。

② マガジンURL → 掲載記事
マガジンURLと件数を指定。マガジン掲載順から指定件数を取得します。

貼り付け内容
丸アイコン＋クリエイター名＋記事タイトル＋記事サムネ。note上の画像キャプションは「〇〇さん」。画像そのものに記事URLリンクを設定します。
両方指定した場合は「スキ側 → マガジン側」の順。記事URLが同じものは重複除外します。
最後は必ず「実績の算数」を1件追加します。途中に同じ記事が含まれていても重複させず、最後へ移動します。
