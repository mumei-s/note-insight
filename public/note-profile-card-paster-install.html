アイコン＋キャプション 貼り付け装置

v1.1.0
① 記事URL / #タグ → スキした人・タグ記事
複数行で入力できます。記事URLはスキした人を取得し、「最初の記事」「固定→最新」「最新記事」から使用記事を選択。#タグは検索結果の記事を直接取得します。
上に並べた入力から優先し、数字指定なら合計件数に達した時点で終了。「全数」なら並べた全ソースを最後まで読みます。

② マガジンURL → 掲載記事
マガジンURLも複数行対応。上から優先して合算し、数字指定 / 全数を選べます。

貼り付けは全自動
「読み込み→全自動貼付」を1回押すだけで、取得 → 対象決定 → 画像生成 → note画像アップロード → 記事URLリンク設定 → 下書き保存まで進みます。＋ボタンや「画像」は押しません。
生成画像は丸アイコン＋「〇〇さん」＋記事タイトル＋記事サムネ。重複記事URLは除外します。
最後は必ず「実績の算数」を1件追加し、途中に含まれていても最後へ移動します。

パネルは小型化。－で収納、×で極小化、タイトル長押しで移動できます。
INSIGHTとは完全に別ツールです。
