DM同期をインストール / 更新

本人通知ツールとは別です。DM同期だけ単独で使えます。

使い方は簡単です。
① DM同期ツールを入れる → ② INSIGHTのDMタブで「DMを連携」 → ③ noteのDMを通常どおり開きます。開いている一覧・会話だけを受動保存し、勝手に別の相手へ移動しません。
文字列画面を開かずにDM同期を更新

EdgeのTampermonkey → ダッシュボード → インストール済み → 無名S note INSIGHT DM同期 →「更新を確認」を先にお試しください。

更新できなければ、下のボタンで最新版のコードだけをコピーし、Tampermonkeyの既存DM同期スクリプトを開いて、エディター内で全選択 → 貼り付け → 保存してください。

既存スクリプトやDM履歴を削除する必要はありません。
通常更新リンク（文字列になる場合は使用しない）
更新状態を確認中…
⚠ 文字列だけが表示され、更新できない場合

表示されただけでは更新されません。Edge → 拡張機能 → Tampermonkey → ダッシュボード → ユーティリティ → URLからインポートへ進み、このURLを貼り付けて「更新 / インストール」を確定してください。既存データの削除は不要です。

Android / Edge・Firefox
Tampermonkeyを有効にして上のボタンを押します。
iPhone / iPad / Safari
UserscriptsまたはTampermonkeyを使い、note.com と mumei-s.github.io での実行を許可します。
PC / Mac
Tampermonkey等のuserscript拡張から同じDM同期ツールを導入します。
DM同期は本人通知Reader・フィルター・通知カテゴリには触れません。noteのDM画面遷移も変更せず、保存先もDM専用です。
