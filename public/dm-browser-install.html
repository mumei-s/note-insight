Tampermonkeyをご利用の場合は「拡張機能 → Tampermonkey → ダッシュボード → ユーティリティ → URLからインポート」で下のURLを取り込み、更新を確定します。SafariのUserscriptsはURLインポートではなく、表示中の文字列をSafariの拡張機能メニューから追加・更新します。

ほかのブラウザの説明
Android / Edge・Firefox
Tampermonkeyを有効にして上のボタンを押します。
iPhone / iPad / Safari
無料のUserscriptsを有効にし、note.com と mumei-s.github.io を許可します。最新版の文字列を開き、Safariの拡張機能メニュー → Userscriptsで追加・更新を確定します。
PC / Mac
Chrome・Edge・Firefox・OperaはTampermonkey、Mac SafariはUserscriptsで同じDM同期ツールを導入・更新します。すでにSafariのTampermonkeyを使っている方も、その拡張機能で続けられます。
