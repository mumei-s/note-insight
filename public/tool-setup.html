INSIGHTをインストール / 更新

本人通知ツール

ここが本人通知の設定・更新入口です。TOPには戻りません。ブラウザに合ったTampermonkey導線から、常に最新版を導入できます。

通知画面は下部固定の5パネルです。
「読込 / 自動ON・OFF / フィルター / 設定 / INSIGHT」。自動ONでは通知一覧を下まで自動で読み進め、確認済みの保存位置までを記録します。次回からはその保存位置を境界にして、新しく増えた通知だけを追加保存します。毎回の全履歴読み直しはしません。
最新版をインストール / 更新

Edge / Firefox / Chrome / Opera：Tampermonkeyの更新画面へ直接渡します。文字列ページは開きません。Safariはuserscript本体を開きます。

最新版かどうか自動確認します。

ブラウザ別インストール

使用ブラウザを確認中…

Microsoft Edge

PC / Android。Tampermonkeyを準備してから上の「インストール / 更新」を押します。

Edge用 TampermonkeyAndroidでもEdge向け公式導線があります。

Firefox

PC / Android。Firefox用Tampermonkeyを入れてから本人通知ツールを導入します。

Firefox用 TampermonkeyAndroid版Firefox向け公式導線もあります。

Google Chrome

PCではChrome用Tampermonkeyから導入します。

Chrome用 TampermonkeyAndroid版Chromeで拡張機能を追加できない端末はEdge / Firefox Androidを使用してください。

Safari / iPhone / iPad

Safari用Tampermonkeyを準備してから本人通知ツールを開きます。

Safari用 TampermonkeyiOS / iPadOSはSafari用の公式導線を使用します。

Opera

Opera用Tampermonkeyを準備してから本人通知ツールを導入します。

Opera用 Tampermonkey

その他のブラウザ

Tampermonkeyの公式対応ブラウザ一覧を確認してください。

公式対応一覧を開くuserscript拡張機能を使えないブラウザでは本人通知機能は導入できません。
導入は3手順だけ① 自分のブラウザ用Tampermonkeyを準備② この画面上部の「最新版をインストール / 更新」を押す③ Tampermonkeyでインストール / 更新 → noteを再読み込み
URLを貼り付ける操作はありません。確認ボタンも不要です。 INSIGHTからこの画面を開けば、ブラウザ別導線と更新ボタンを同じ場所で使えます。

Tampermonkeyの「ユーザースクリプトの更新を確認」からでも更新できます。同じ本人通知ツールを上書き更新し、二重導入にはしません。
