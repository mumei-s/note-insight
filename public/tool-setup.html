ブラウザ別インストール

使用ブラウザを確認中…

Microsoft Edge

PC / Android。Tampermonkeyを準備してから上のV3ボタンを押します。

Edge用 TampermonkeyAndroidでもEdge向け公式導線があります。

Firefox

PC / Android。Firefox用Tampermonkeyを入れてからV3を導入します。

Firefox用 TampermonkeyAndroid版Firefox向け公式導線もあります。

Google Chrome

PCではChrome用Tampermonkeyから導入します。

Chrome用 TampermonkeyAndroid版Chromeで拡張機能を追加できない端末はEdge / Firefox Androidを使用してください。

Safari / iPhone / iPad

Safari用Tampermonkeyを準備してからV3を開きます。

Safari用 TampermonkeyiOS / iPadOSはSafari用の公式導線を使用します。

Opera

Opera用Tampermonkeyを準備してからV3を導入します。

Opera用 Tampermonkey

その他のブラウザ

Tampermonkeyの公式対応ブラウザ一覧を確認してください。

公式対応一覧を開くuserscript拡張機能を使えないブラウザでは本人通知機能は導入できません。
導入は3手順だけ① 自分のブラウザ用Tampermonkeyを準備② この画面上部の「V3.2.28をインストール / 更新」を押す③ Tampermonkeyでインストール / 更新 → noteを再読み込み
URL貼り付けは不要です。 INSIGHTからこの画面を開けば、ブラウザ別導線とV3更新ボタンを同じ場所で使えます。

同じV3を上書き更新します。旧V3と二重導入にはしません。
