PRIVATE NOTE NOTIFICATION IMPORT

note通知を取り込む

noteの通知ページに表示されている返信・コメント・スキ・フォロー・マガジン・購入・チップなどをINSIGHTへ保存します。noteのパスワードは使いません。

① 取込コードを作る

最初に1回だけ作成。再発行すると前の取込コードは無効になります。

準備中…

② noteの通知ページで実行

1
上の「取込コードを作る」→「コードをコピー」

コピーした文字列は javascript: から始まります。

2
ブラウザのブックマークURLへ貼る

名前は「INSIGHT通知取込」などでOK。URL欄をコピーしたコードへ置き換えます。

3
noteの通知ページを開き、保存したブックマークを実行

現在画面に読み込まれている通知を抽出してINSIGHTへ送信します。下までスクロールしてから実行すると、画面に読み込まれた分を多く取得できます。

note通知ページを開く ↗

ブラウザによってブックマークレットが使いにくい場合は、下の貼り付け取込を使えます。

貼り付け取込

note通知の文章をコピーして貼り付けても保存できます。通知ごとに空行を入れると分割します。

取り込まれる種類

返信 / コメント / スキ / フォロー / マガジン追加 / 購入 / チップ・サポート / 話題 / 引用など。INSIGHT側で分類して保存します。
