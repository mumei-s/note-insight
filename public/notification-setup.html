本人通知・統計連携

参加者もOWNERも同じv2.9.17共通ツールを使います。旧v2.xが別スクリプトとして残っている場合は削除または無効化し、最新版1本だけ有効にしてください。

本人通知・統計 v2.9.17 を設定／更新
① INSIGHTから設定／更新
端末とブラウザを自動判定して、対応するインストール画面へ進みます。
② 対応ブラウザでTampermonkeyへ
AndroidはEdge / Firefox、iPhone / iPadはSafari、PCはChrome / Edge / Firefox / Safariの対応環境で進めます。
③ インストール後にnoteで実動確認
「入ったはず」ではなく、note上でv2.9.17が実際に動いたことを確認します。
④ 成功したら元のINSIGHTへ自動復帰
本人通知・統計設定の元いた画面へ戻ります。INSIGHTのログイン状態は消しません。
v2.9.17では、Tampermonkeyが動いているnoteタブが生きている間、通知数変化・画面更新・定期確認の3系統で未保存通知を差分保存します。保存確認済みの通知にはnote側で小さく「保完」を表示し、未保存だけを優先して再確認します。

note通知画面はINSIGHTを常時表示し、その他の操作は「通知操作」1ボタンへ収納します。通知操作は長押しで好きな位置へ移動でき、その位置を保持します。

通知操作をタップすると、追加読込・保存 / フィルターON・OFF / 設定を開きます。設定ではフィルターグループを作成し、クリエイターをnote URL / ID / @IDのどれでも追加できます。

「あなたの記事がマガジンに追加されました」「チップ・サポート」は重点再確認対象です。通常保存とINSIGHT反映は自動、手動の「追加読込・保存」でも未保存判定を使って補完します。
※ 本人通知は現在noteにログイン中のnote IDへ保存します。INSIGHTで別アカウントを表示していても、その別アカウントへ混ざりません。サーバー側でもnote IDと連携tokenが一致しない保存は拒否します。
※ Android Chromeの本人通知ツールは非対応です。INSIGHT本体は利用できます。Yahooアプリ内ブラウザは本人通知ツール非対応です。
