参加者もOWNERも同じv2.9.18共通ツールを使います。旧版が別スクリプトとして残っている場合は削除または無効化し、最新版1本だけ有効にしてください。

本人通知・統計 v2.9.18 を設定／更新
① INSIGHTから設定／更新
端末とブラウザを自動判定して、対応するインストール画面へ進みます。
② 対応ブラウザでTampermonkeyへ
AndroidはEdge / Firefox、iPhone / iPadはSafari、PCはChrome / Edge / Firefox / Safariの対応環境で進めます。
③ インストール後にnoteで実動確認
note上でv2.9.18が実際に動いたことを確認します。
④ 成功したら元のINSIGHTへ自動復帰
INSIGHTのログイン状態は消しません。
v2.9.18では、note通知を開いた時点で未保存通知の自動確認を開始します。読込中は「保存中… ページを閉じないでください」、完了時は「保存完了」と表示します。

保存確認済みの通知だけ小さい「保完」を表示します。保完状態は保存記録から再表示するため、通知画面を閉じても保存済み判定そのものは消えません。

通常操作は通知欄外の細いパネルへ置き、追加読込・保存 / フィルターON・OFF / 設定 / INSIGHTを利用できます。設定ではクリエイターをnote URL / ID / @IDのどれでも追加できます。

「あなたの記事がマガジンに追加されました」「チップ・サポート」も重点確認対象です。
※ 本人通知は現在noteにログイン中のnote IDへ保存します。INSIGHTで別アカウントを表示していても混ざりません。
※ Android ChromeとYahooアプリ内ブラウザは本人通知ツール非対応です。
