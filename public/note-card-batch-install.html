v18.9.0：極薄＋通知を新規構築し直しました。
旧v18.8系の「宵空セット」「追加＋カード続き」「画像アップロード復旧」などは今回の実行経路から外しています。古い仕様を継ぎ足さず、現在のスキ・現在の記事から新しい対象一覧を作ります。

最新から再構築：#イケメングランプリ宵空カップは現在の全記事を先頭に保持。指定2記事の現在のスキ一覧を再取得し、#投稿者との重複を除外。非#は「今日・昨日の最新 → 固定 → 最新」で現在の記事を選びます。最新の明示追加プロフィールも合流し、最後は「実績の算数」です。
極薄サムネイルは860×140をGitHub側で作成済みにして、note側で300枚以上を再アップロードしません。本文には完成済み極薄画像＋記事リンク＋名前さんを順番に配置し、区切り保存します。

カード開始：note正規URLカード処理だけを使います。iframeの403表示は完成判定に使いません。8件ごとに下書き保存、32件ごとに45秒休止して連打を避けます。403/429/通信失敗が出た場合は完成分を保存して停止連打せず、長めの待機後に同じ1件から再開します。
カード削除：公開・通知後、今回作成した通知カードだけを削除し、極薄サムネイルは残します。

INSIGHT本体は変更しません。旧v18.8系の途中記録は最新再構築時に今回の管理記録へ切り替えます。
