極薄＋通知ツール

v18.8.18
「追加＋カード続き」にまとめました。
不足画像の追加 → リンクと保存の確認 → 通知カードの続きを、1つのボタンで進めます。「画」「不足画像のみ追加」「追加分」は個別に押す必要がありません。
追加に失敗した場合はカード作成に進まず、既存の本文・画像・カードを保持します。画像受付／画像送信のどちらで失敗したかと、取得できたHTTP状態を表示します。自動再送はしません。
保存が確認できない編集タブは閉じたり再読み込みしたりせず、「本文の控え」から現在の本文を書き出してください。
下書き保存と控えを確認 → 下のボタンで更新 → 編集画面を開き直し、v18.8.18を確認 →「全件確認」。
通常時は「追加＋カード続き」で不足分から進めます。「削（一括）」は公開・通知後の操作です。
はなさん・しろのあるさんを追加して全313件、#の42記事が先頭、最後は「実績の算数」。完成は本文内のカードと保存済み下書きの全件照合で判定します。
v18.8.18では、Androidで一時的に出るHTTP状態不明（status 0）だけでは停止しません。画像が実際に失敗したことまで確認してから停止します。v18.8.17で残ったstatus 0停止記録は新版で無効化します。401/403/429は従来どおり即停止します。
403が続いている間は「追加＋カード続き」「通信停止解除」を押さないでください。この更新は403を解消するものではありません。失敗していた操作が通常どおり使える状態に戻った後に解除してください。端末上の全件完了・通知受信は未確認です。
「旧版」「複数版が混在」と出る場合は、Tampermonkeyで極薄ツールを最新の1つだけ有効にしてください。以前のスクリプトを削除する必要はありません。
