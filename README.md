# 無名 S note｜note INSIGHT

GitHub Pagesで開くPWA画面です。会員認証、管理者承認、分析履歴、差分更新は公開コードに秘密情報を置かず、既存の保護されたAPIで処理します。

## 公開

`main` ブランチへの更新後、GitHub Actionsが自動でビルドし、GitHub Pagesへ公開します。

## 安全設計

- 入口パスワードはコード内に保存しません。
- 端末識別子と会員トークンは利用者のブラウザ内だけに保存します。
- 別note IDへの変更、会員承認、脱退、分析対象の制限はAPI側でも確認します。
- 公開リポジトリにはメールアドレス、管理者コード、セッション秘密値を置きません。
