# ネイティブ🔔一覧の横はみ出し

filter 4.2.16。添付ではnoteヘッダーが画面内に収まる一方、通知タブと行が画面の右へ出ている。現在のfilterが枠幅を拡大する処理は見つからなかったが、通知枠に固定最小幅が残る検証用画面で同じはみ出しを再現した。

767px以下のレイアウト幅で、表示中の確認済み通知枠または通知行の実寸が画面を超える場合だけ、通知枠から一覧までの最小幅・最大幅・box-sizingを調整する。枠に収まらない行も同じ枠幅に収める。正常な一覧、デスクトップ、note全体のbodyには変更を加えない。

拡大移動で狭くなるVisualViewportを本文幅には使わない。幅の変更前に閲覧中の行の位置を保存し、折り返し後の位置を復元する。機能OFF・一覧離脱では元のインライン値と優先度を戻し、後からnote自身が変更した値は上書きしない。

新規7件は幅変更・初回判定前の閲覧位置・横画面・OFF復元・追加の通信や書き換えループがないことを検査する。Chromiumでは344px画面に376pxの通知枠と500pxの行を置き、修正後は通知枠・行・文書幅がすべて344pxに収まり、430pxへ回転した場合も430px内であることを確認した。Android Edge実機の検証とは区別する。

通常のモバイル一覧では、DOM世代・画面幅・枠の実寸が同じ間は幅検査を再利用する。300行を3回設定再確認しても追加の行幅測定は0回。通知の追加・外部の幅変更時は再測定する。

ブラウザバーの開閉など高さだけが変わるresizeではフィルターを再処理しない。操作列のVisualViewport追従と、本文の画面幅補正をそれぞれ必要な変更時に限る。
