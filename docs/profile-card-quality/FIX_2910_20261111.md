# 2.9.10 — 通知カードのカーソル指定

報告画面のエラーは「通知カード用URLのカーソル位置を確認できません」。URL段落を配置する前の Selection.near による位置確認で、目的位置以外のカーソルが返ると、正規カードの変換を要求する前に終了していた。

極薄サムネイル単独版では、エディター自身の Selection.fromJSON に登録された text 選択を使い、検証済みの URL 段落末尾を明示的に指定する。fromJSON を使えない場合のみ、従来の near が正確な位置を返したことを検証して利用する。モバイルで focus 後にカーソルが戻った場合も、同じ URL 段落を再確認して指定し直す。本文と URL の一致、変換直前の選択、重複防止、途中記録の検査は維持する。

共有 core や INSIGHT 本体は変更せず、単独配布物の生成時だけ適用する。既存の紹介画像は保持し、更新・編集画面の再読込後、配置場所をタップして「② 通知カード」で再開する。

旧処理で同じエラーを再現する検査を含む新規9検査を追加。通常・履歴、近傍位置への移動、focusによる移動、ブロック選択クラスからの切替、互換API、位置不明時の無変更、中段への挿入、失敗後の再試行を確認。関連検査158件成功、旧版比較用29件は既存の条件でスキップ。両配布物の構文・再生成を確認。利用者の Android/Edge での実行は未確認。
