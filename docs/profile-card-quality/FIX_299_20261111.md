# 2.9.9 — 保存済みの要約エラーの再取得

2.9.8 は未貼付の行だけを再取得していたため、旧版が「無料公開本文を取得できません」を焼き込んだ画像は、更新後に再開しても完成扱いで残った。

「再開」で保存済みの完成画像も確認し、要約エラーがあれば本文を再取得する。元記事を読めなければ同じクリエイターの範囲内の別記事へ切り替え、見つからなければ除外する。本文、画像、リンクの対応を検証してから、最初のエラー行以降の作成済み出力を巻き戻し、通常の逐次アップロードで作り直す。前の成功分と元本文は保持する。

同じ記事の通知カードは保持する。記事の差し替え・除外が発生した場合、その行以降の記録済みカードを除去し、「② 通知カード」で正しい記事から再開できる。画像の再作成後は残存カードの位置を再確認する。更新だけで自動実行せず、利用者の「再開」で処理する。

変更は極薄サムネイルの単独配布物、生成アダプター、関連テストとこの記録に限定。INSIGHT 本体やバックエンドは変更しない。

検証: 通常・スキ履歴、極薄・中型、旧データからの更新、成功分の保持、別記事への切替、対象者の除外、通知カードとの対応、重複防止、一時停止後の再読込、本人確認の矛盾時に書換前で保留することを確認。いおりさんの記事の公開 API を再取得し、無料本文から抜粋できることも確認した。

実機の Android/Edge での実行は未確認。ローカル Chromium は実行環境の socket 権限で起動できなかった。
