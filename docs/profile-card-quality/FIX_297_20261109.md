# 2.9.7：スキされた日と対象記事を指定して極薄を作成

「自分のスキ履歴」に今日・指定日・期間・全期間、全記事・記事指定を追加。初期値は今日（日本時間）・全記事。過去に公開した記事への本日のスキも含む。指定時は一致する全員（最大1500人）、全期間・全記事では既存の件数設定を使用。「200人に設定」は全期間・全記事・200人へ戻す。

取得APIの `filtered-likes` だけを拡張。`liked_at` と `occurred_at` に日本時間の開始日0時以上・終了日の翌日0時未満を適用し、記事条件も重複除去より先に適用。`insight_public_likes` と本人の記事への `notification_type=like` を統合し、人物キーと正規化したnote IDで重複を除く。コメントへのスキ、集計通知、人物なし、他会員のデータを含めない。取り込み日時・初回観測日時をスキ日時に代用しない。

サーバーの契約バージョン・条件の一致・上限を検証してから編集画面へ返す。編集側でもスキ日時・対象記事を検証。0件・条件不一致・上限超過時に、無関係な直近履歴へフォールバックしない。新しい取得結果と紹介可能な記事一覧を準備してから旧作成分を消す。日付指定の再開始は同じ日でも再取得し、「再開」は保存した日付・一覧・貼り付け進捗を維持する。日付条件は作成記録と読み込み途中記録へ保存。

INSIGHT本体・通知取得・フィルター・DBスキーマは変更しない。変更対象は極薄単独配布2本、生成元、独立した履歴読取ページ、専用export関数、版表記、検証。export関数は既存の会員認証と会員別スコープを保持。

2026-11-09の保存データ照合：記事別履歴114人、記事へのスキ通知116人、統合重複除去116人。確認時の最終スキ22:43 JST。これは保存済み履歴の対象数であり、紹介可能な公開記事・画像の有無によって貼り付け人数は変わり得る。

検証：新規10件成功（日本時間境界、期間、記事指定、重複除去、1000件超ページング、別会員、空・不正条件、上限、契約不一致、実ProseMirror/canvasでの生成・保存・停止再開、再取得してから旧作成分を削除）。既存経路189件、品質・編集画面分離20件成功。TypeScript/Viteビルド成功。生成物の再構築と構文確認成功。
