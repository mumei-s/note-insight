# 極薄・中型の常用化と速度改善（2.9.2／2026-10-31完了）

変更前は **2.9.1 / `260d7c3ec44b7faf7171e4f4ecd2160ec047146b`**。main・更新案内・実配布・生成元を確認してから作業した。利用者からは同版の「#」で正常動作したという実機報告がある。今回の2.9.2のスマートフォン実機確認とは区別する。

## 今回の操作と出力

- 「#」「記事URLのスキ」「マガジンURL」を同じ入力欄に複数指定できる。#同士、同じ行、改行、全角＃、noteのhashtag URLに対応。入力順に採用し、同じアカウントは1回だけ紹介する。
- どの入力元でも、その人の **最初／固定→最新／最新／固定のみ** を選ぶ。「固定のみ」で固定記事を確認できない人を最新記事へ差し替えない。未確認人数を完了表示に残し、根拠のある候補内訳を今回の進捗へ保存する。
- 指定件数／全数を維持。「実績の算数」は件数外の最後の1件。入力・人数・アカウント・内容が毎回変わっても検査する。
- 極薄860×140、中型860×360と、名前／プロフィール／記事の要約・抜粋を選ぶ。新しい極薄は名前と画像、選んだ紹介文は直前の装飾した段落。中型は見本のように画像と説明を横に配置する。記事名や元のプロフィールはデータに保持する。
- 要約は公開部分の抽出型。無料と確認できる本文、明示的な無料本文、課金境界より前、公開リードだけを使用する。有料本文を読み出す仕組みや有料AIは追加しない。長文は「抜粋」、材料不足は未取得と表示し、タイトルだけで要約を捏造しない。
- 旧保存分に表示設定が無い場合は旧形式を維持。新しい作成分では表示設定を固定し、再開時に操作欄を変更しても途中から混ざらない。
- 画像全体・アイコン・記事画像へ、画像描画後に濃色と白の縁を描く。白と黒の画面・白と黒の素材の両方で境界を確認する。
- 50種／200種で折り返すだけの配分をやめ、既存の柄に形の異なる装飾を加える。指定件数を増やしても同じ柄に戻らない。既存のデザイン番号と貼付済み画像は保持する。
- ハロウィンと特別企画の操作欄を外し、通常の入力・再開・一時停止・通知カード・通知カードのみ削除・今回分全削除をまとめた。旧ハロウィン保存分の復旧に必要なデータと処理は保持する。購入記事紹介は専用版のままで復活させない。
- 今回分全削除は入力・件数・表示設定を保持する。手動の同文段落を所有物と推測せず、自分の紹介文と画像の対応を確認して削除する。

## 検査と再開

2.9.1の生記事・プロフィール・FileのID照合、既知の保留、保存確認、挿入位置、未確定の通知カード、リンク・キャプションの確認を残す。表示名・話題・手動改行を理由に別人としない。区切りの上下に別人の紹介がある正常例も維持する。

追加した表示本文についても、プロフィール／無料本文／公開リードの取得元アカウント・記事IDを照合する。材料不足は合格と呼ばない。既存の保留はOFF・例外・再読み込みでも残し、履歴の開始し直しからも飛び越えられない。

末尾の実績記事は画像取得失敗だけで中断せず、同じ人・同じリンクの画像未設定表示で完了する。実績記事の投稿者IDが違えば従来どおり保留する。

新しい上側紹介文は、URLごとの生成記録と自分の画像の直前という構造で対応づける。後方にある同文の手動段落へ飛ばさない。途中失敗後に文章を二重に作らず、再取得で既存の紹介文が変わる場合は保留する。
