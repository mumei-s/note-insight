# 🔔操作列とモバイルの表示領域

controls 1.5.9。従来の操作列はレイアウト領域の左右8px・下8pxだけで固定され、ブラウザバー、キーボード、拡大移動で実際に見える範囲が小さくなった時も追従しなかった。

VisualViewportの幅・高さ・位置から、操作列の横幅と下端の隠れ量を計算する。resize/scroll/orientationchangeを同一描画フレームへまとめ、同じ値を繰り返し書き込まない。API未対応・一時的な不正値の場合はレイアウト領域に戻す。

32pxボタンと読める状態・エラー本文、保存設定、通知一覧のスクロールと拡大率を維持する。表示領域の更新では本人取得や通知読み込みを起動しない。OFF後の表示領域変更でも操作列を再生成しない。

新規viewport検査6件と、既存の状態表示・Reader操作・記事からの復帰を併用した29件が成功。Chromiumによる描画検査は実行環境のANGLE/Vulkan初期化で開始できず、Android Edge実機での検証を完了したとは主張しない。
