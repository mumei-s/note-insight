# Dashboard同期 1.6.5

公式Dashboardのヘッダーにある通知ベルのクラス名を通知シートと誤認し、小型パネルを消して読込を抑止していた。ベルだけの表示を除外し、実際の通知シートでは従来通りDashboardの読込と表示を止める。

小型パネルに自動／手動、読込／停止、詳細、OFFを表示する。ボタン高28px、文字10px、最大幅520px。下段に小さく「ON/OFFは設定から」の設定リンクを表示する。通常は自動。手動設定はGMストレージに保存し、再訪・別タブにも反映する。手動中は公式通信の到着、通知シートからの復帰、起動イベントで自動保存を始めない。利用者が押した読込や連携操作は実行する。

OFFは従来の設定キーを使ってパネルを消し、設定画面から再びONにできる。本人通知のON/OFFとは独立している。
