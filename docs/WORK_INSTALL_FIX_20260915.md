# 2026-09-15 更新・固定パネル修正

開始main: dc1b6c0cc0d1db872e1472a66bc0e8eb8649fdad。最新3.2.2の直接DOMパネルを維持。

- 3.2.3は本体同梱の1本。外部@requireの取得が終わるまで4ボタンが起動しない依存を除去。
- 更新はqueryなしの.user.jsを別タブへ開き、導入センターを残す。既存Tampermonkeyは再インストール不要。
- 文字列表示時は同じ画面に更新URLコピーと拡張の更新確認・URL取込を案内。
- 自動往復を廃止。明示的な更新確認で新しい確認日時と版番号が一致した場合だけ成功。
- 格納なし。4列パネルは通知画面下部に10px以上の余白で固定。
- パネル自身のDOM変更による再描画を抑制。互換タッチのpreventDefaultを外しpointerupとclickの二重動作は防止。
- 読込時はフィルターOFF。読込完了時は操作ロック解除。エラー表示は残す。
- 既存の本人連携トークンは保持。未連携時は現在のnote IDと発行先IDを照合して保存。
- 四つの操作、二重発火、更新URL、古い保存版の誤成功防止をDOM試験に追加。

Android実機のTampermonkeyによるリンク捕捉・拡張インストールは未確認。ページから拡張のインストールを強制することはできず、全端末の成功とは表記しない。公開完了はGitHub Actionsで確認する。
