# Dashboard同期 1.6.6：公式 /dashboard でパネルが出ない

利用者が1.6.5更新後もnote公式ダッシュボードにパネルが出ないと報告。本人が画面URLは `note.com/dashboard` と確認した。

1.6.5ではcoreの起動・SPA遷移・画面表示・通信監視・scopeと、wrapperの起動対象が `/sitesettings/stats` に限定されていた。したがって `/dashboard` ではパネルを作らない。前回のベル検出修正では、このURLの抜けを解消できていなかった。

両方の公式URLと配下のタブに対象を拡張する。通常の記事や他のページへは表示しない。自動／手動、停止、保存照合、通知画面中の非表示、設定OFFの動作を維持する。配布core・wrapper・manifest・更新表示は1.6.6へ揃え、coreのrequireは166へ更新する。

追加の6件で、/dashboard、末尾スラッシュ、記事タブ、通常ページからの自動／手動のSPA遷移、設定OFF→ONを検証。修正前1.6.5は全6件失敗。修正後は全6件成功。従来の「/dashboardは公式画面ではない」というテストも、利用者が確認したURLに合わせて訂正し、類似の別URLを除外する2件の検証へ変更した。Dashboard・設定・配布版の回帰テストとTypeScript・Viteビルドで確認する。

Android実機は直接操作できていない。利用者が確認したURLと、同URLでの再現テストを根拠に修正した。
