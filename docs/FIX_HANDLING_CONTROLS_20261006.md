本体 2026.10.06.3 / 本人通知ツール 3.6.36。ダッシュボード・DM同期の版と処理は変更しない。

## 実装
- スキ履歴と本人通知の対応済み操作を高さ30px、短い表示、共通の紺・水色へ統一。文字はモバイル・タブレット・PCそれぞれのメタ文字サイズを使う。説明はアクセシビリティラベル・titleで保持。
- 押した直後に対応状態を表示、軽い一度の発光。保存中は小さなインジケーター、保存失敗時は元へ戻して理由を表示。縮小モーション設定を尊重。
- スキ操作後の一覧全件再取得を廃止。保存済みページの該当行だけを更新し履歴を捨てない。
- 本人通知に「すべて / 未対応 / 対応済み」を設置。カテゴリ・日付を保ち、サーバー全履歴に対応状態フィルターを掛けてからページ分割。
- 本人通知の人物に★。既存の insight_favorite_creators を本人範囲で使い、通常履歴と同じプロフィールURLなら既存キーを再利用。登録・解除・一覧は共通。★お気に入りから既存一覧へ移動。
- 本人通知の保存前はメモリー内だけを切り替え、サーバー確認後に永続履歴へ反映。読込とアイコン補完の応答が未保存操作を上書きしない。保存中のページ変更・失敗復元・アカウント変更を保護。
- 公式🔔パネルは操作段、その下に進捗と「ON/OFFはメイン🔔から」を同居させた2段。長い失敗理由は必要な分だけ折り返して保持。

## 境界
既存テーブル・認証・権限・通知分類・Readerの保存処理を維持。新しい★操作は通知IDを本人範囲で検証し、人物URLをサーバーから取得する。クライアント指定の他人のIDや人物情報は採用しない。旧通知の対応済み識別は前回の個別キーを維持。
