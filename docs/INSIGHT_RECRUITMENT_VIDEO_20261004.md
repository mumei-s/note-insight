# INSIGHT recruitment video

Public page: https://mumei-s.github.io/note-insight/recruitment/

The page plays the 41-second MP4 directly, with native browser controls and inline mobile playback. Viewing the introduction requires no account or external video service. INSIGHT itself is membership-only. Every participation CTA opens https://note.com/ss_yr/membership; there are no links to the INSIGHT TOP.

The video uses the current public TOP and actual INSIGHT screenshots supplied by the owner. Participant names, IDs, avatars, article titles and search values are cropped out or covered with opaque pixels before animation. Aggregate analysis counts are preserved. Captions and an original instrumental soundtrack are included.

The video, cover, page copy, Open Graph metadata and end-of-playback message all state the membership restriction. The former TOP registration steps and TOP URL have been removed from the video. Versioned media URLs prevent reuse of the earlier files after this correction.

For note, paste the page URL into an empty paragraph. It is a link card leading to the video page; it is not an in-article embedded video player. Open Graph metadata includes the provided 1920 × 1080 cover.

Scope: standalone public recruitment page and its media. There is no change to authentication, data storage, existing application routes, userscripts, or the database.
