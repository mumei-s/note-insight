# ダッシュボード パネル ON/OFF — 1.6.2

対象はダッシュボード同期だけ。本人通知のフィルター・ON/OFF、DM、分析の集計・保存形式は変更しない。

## 修正

- INSIGHTの分析カードとダッシュボード設定画面に「ダッシュボード パネル ON/OFF」を追加。
- note側の小型パネルにOFFボタンを追加。OFFにするとパネルと余白を除去し、自動読込を停止する。
- 設定を同期ツールの保存領域に保存。再読込・再訪後も保持し、別タブにも反映する。値変更通知がない環境ではフォーカス復帰時に反映する。
- OFF起動では本人確認通信や読込用通信監視を開始しない。実行中のOFFでも以後の巡回を停止し、保存済みデータは保持する。
- noteの🔔が通常のリンク付きシートとして表示される場合も検出。URLが変わらなくてもダッシュボードのパネルを隠し、読込を一時停止する。
- 設定確認前の自動連携、OFF後の遅延応答による画面移動を防止。OFF→ONを続けて操作した場合は古い読込を終了してから再開する。
- OFF中の巡回タイマーを停止し、画面変更時の走査を抑止。パネルのサイズ監視も破棄する。
- 設定の保存失敗は成功と表示せず、エラーと再試行を表示する。

## 検証

- 新規の動作検証11件：GM新旧API、別タブ、再訪、ON復帰、パネルのOFF、🔔シート、遅延応答、保存失敗、無関係なメッセージ、設定読出し待ち、連携中のOFF→ON。
- 既存を含む公開ゲート373件（カード4、共通79、動作290）とビルド。
- 実端末の拡張機能による動作確認は未実施。自動検証はJSDOMによる操作・通信・保存の検証。
