# 通知の停止後の保存継続

「停止」とページ移動は、未取得のnote通知ページの通信を止める。すでに取得した通知の保存・本人照合・確認応答待ちは継続する。保存前に永続journal/outboxへ書き、確認された署名だけを消す。全ページを取得する前に停止した場合は、取得済み分を保存した後、残りページの取得位置を残す。

保存通信と本人照合にも独立した期限を設定し、無応答や通信失敗なら未確認データを保持する。完全なページ移動で実行環境が消えた場合も、次回の通知読み込みで残りから再開できる。新着確認は従来どおり保存済み署名との差分を扱い、同じ通知を繰り返し保存しない。

検証: notification-window / feature / network / tools-release 30件成功。69件の保存中停止、次ページ待機中の離脱、3回目の追加0件、保存先の無応答、保存先確認だけ失敗、別人への切替を確認。
