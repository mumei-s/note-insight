# 本人通知：Edge下部操作列の断続的な位置ずれ（2026-11-02）

対象：`note-insight-notification-controls-v1.js` 1.5.10、本人通知V3.6.67。Android Edgeで通知一覧の下部操作列がブラウザのアドレスバーに一部隠れる場合を想定。

旧1.5.9は`document.documentElement.clientHeight - visualViewport.offsetTop - visualViewport.height`だけで操作列の下端補正を決めていた。ブラウザのUI出入時に固定要素の実際の基準面とその値が一時的に一致しないと、補正が不足または過剰になる。

新実装は幅を合わせた後に、**操作列の実際の矩形位置**から可視領域下端までの差を測って補正する。DOMで実寸を取得できない場合は旧推定式へフォールバック。重複補正を避け、`resize`、`scroll`、`touchend`、復帰時に描画フレームをまとめて再検査し、タッチ終了後だけ340msで追確認する。

既存の通知収集、読込再試行、フィルター、記事からの復帰、画面スクロール、操作列のON/OFF状態は変更しない。更新時は`@version`と`@require`のキャッシュ識別子を上げ、既存インストールに新しい位置計算を読み込ませる。

新規テストはHTML表示高さと固定要素の基準高さが異なるケース、ブラウザ側の自動固定補正、タッチ後の遅延変化、ズーム移動と通信件数の不変を模擬する。**実機Edgeでの合格を示すものではない**ため、更新後のスクリーンショットでの確認が必要。
