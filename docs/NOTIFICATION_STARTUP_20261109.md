# 本人通知：起動停止とパネル再表示漏れ（2026-11-09）

対象：本人通知V3.6.68、フィルター4.2.18、操作パネル1.5.11。

利用者報告は「通知パネルが消え、登録済みのフィルターも効かない」。利用者端末の実行ログは取得していないため、今回の発生トリガーは未確定。以下はコード検査とローカル再現で確認した不具合であり、端末での直接原因を確定した記録ではない。

- `@run-at document-start`で`document.documentElement`がまだ存在しないと、フィルターの`MutationObserver.observe(null)`が同期例外を投げる。読み込んだフラグだけが残り、フィルターAPIの公開と後続モジュールの実行にも到達しない。APIを先に公開し、DOM監視とスタイル設置をDOMContentLoaded後に開始する。先行する機能ON通知からのrefreshもroot準備前は待機する。
- 操作パネルはchildListだけを監視していた。既存の通知一覧をhidden・style・class・aria-hiddenだけで開き直すと再表示されない。通知要素とその親に限って属性変更も拾う。無関係の画面変更や自分のパネルは除外し、通信による常時監視は追加しない。

登録人物・フィルターON/OFF・明示的な一時停止・保存済み通知の設定は変更しない。新しい@requireキャッシュ識別子で修正版を取得する。
