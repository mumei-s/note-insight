## 今回の依頼と実装

- TOPの重複したINSIGHT見出しを「メンバー紹介」に変更。説明・参加手順・端末案内の文字と余白を縮小し、下部に有限の登場・光の演出。
- 速度は再生操作と同じ行の小さなLv.1〜5。従来の最遅を削除し最速を追加（3秒、2秒、1.5秒、1秒、0.7秒）。標準2秒。旧保存設定を移行し、再生状態・人物とともにページ移動後も保持。
- 分析入口を通常分析、ダッシュボードINSIGHTプロ、本人通知分析、総合判定の4パネルへ。選択した分析のみ表示・取得。通常分析は既存のツール不要の公開データ分析を復帰。
- 本人通知の人物・交流分析は本人通知分析パネルへ。総合判定は既存の成長判定・記事評価・同日照合を集約し、未知値や不足データを判定に補完しない。
- 導入状況・版確認・更新・連携は既存⚙設定ページへ。各分析から本人IDと戻り先を維持。設定を開くだけで連携を開始しない。
- 分析表示中は4パネルを小さな切替操作に縮小。「分析」を再度押すと4パネルの一覧へ戻る。
- 円グラフは浮上して停止。棒・線・点に組み立てときらめき。最終座標と比率は維持し、画面外・バックグラウンド・動きを減らす設定では停止。
