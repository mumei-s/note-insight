## 修正

Dashboard設定と本人通知インストールの共通料金枠を削除。iPhone/iPad SafariとMac SafariのTampermonkeyリンクに「有料・INSIGHTとは別料金」を表示。他のブラウザ案内に共通警告を出さない。

Dashboard設定の先頭に「連携して公式データを読み込む」を配置し、版数・ブラウザ手順・任意の本人通知を折りたたむ。本人通知の導入なしでもDashboardを連携できる。未ログイン時は実際のログインリンクを表示する。

公式Dashboardのパネルは余白と行数を減らし、未連携・失効時の主操作を「連携して読み込む」に変更。本人のnoteアカウントを確認して設定へ進み、明示されたauto=1を一度だけ消費して本人照合と公式読取へつなぐ。旧版はwrapperが直接ステータスDOMだけを書き換え、coreの再連携リンクを表示する処理を通っていなかった。ステータスと主ボタン状態を同じイベントで更新する。本人照会に10秒のタイムアウトを設ける。

分析更新はReactが所有するネイティブリンクでdashboard-setup.htmlへ進む。分析パネル自身に点滅しない点灯と「更新あり」を出し、更新検出後は通常の分析ボタンへ戻す。旧統合案内はDashboard用の直接子リンクを探し、見つからないと本人通知インストールへ送っていたため廃止。本人通知だけの更新を分析の更新として表示しない。
