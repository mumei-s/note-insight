# フォロー照合・履歴の保存済み表示

照合の順番・関係条件・検索・ページごとの保存済み表示を本人アカウント別に保持。INSIGHTを閉じて再度開いたときも、その表示を先に復元し、サーバーに保存された最新結果を確認する。表示取得ではnoteの人物一覧を最初から走査しない。同時の同じ表示要求は一つにまとめる。

人物照合の実データと差分履歴は既存の保存処理を維持。再フォロー後も履歴を残し、同じ状態と古い結果を追加しないことを既存テストで確認。

検証: social-mutual / social-history / social-comparison-review 23件、social-view-cache 2件、ビルド成功。再起動での復元、本人切替、遅延応答、通信重複を確認。
