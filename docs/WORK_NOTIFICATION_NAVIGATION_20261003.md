# INSIGHT 2026.10.03.21 — 本人通知の導線とクリエイター部

開始時 main は `a0358059a0641fd29362df8292de7d5b2dc14ce8`。この更新はUIのみ。本人通知ツールは `3.6.23`、分析 `1.6.4`、DM `1.4.9` のまま。

- メインの本人通知と歯車が同じ行き先だったため、本人通知の歯車だけを撤去。分析の設定は維持。
- `notification-connection.html` の最上部に「フィルター設定」「保存済みの本人通知」の2パネルを配置。statsで確認したnote IDを両方のURLへ渡す。
- 添付の `3.6.20 → 3.6.23` の更新表示に対し、状態欄のすぐ下に押せる更新ボタンと手順を追加。既存の正規インストール画面へ戻り先付きで進む。戻る・フォーカス・ツールversion通知により表示を再確認し、最新版なら更新案内を消す。拡張機能の二重導入や自動再連携はしない。
- 下部の項目バー、現在の項目、通常データの通知件数の表示名を「本人通知」へ変更。内部キー `notifications` は維持。

- 名前・画像・note IDは現在のアカウントとAPIレスポンスから表示。共通の背景ロゴ「無名 S note / INSIGHT」は全員共通。2つの異なるプロフィールで名前・画像・リンクが切り替わることを回帰テストで検証。

境界に従い、本体はファイル／機能ごとにコミットを分離する。認証・本人通知Reader・Supabase・保存データ・メンテナンス無効・下部ナビ静止は維持する。
