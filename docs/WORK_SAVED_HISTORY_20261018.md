# 2026-10-18 保存済み履歴の初期表示と取得範囲

対象依頼: 「なんでスキ履歴とかは前回までのが表示されておらず、読み込みになるの？全部読み込んでない？」。INSIGHT本体 `2026.10.18.1`。本人通知3.6.38、ダッシュボード1.7.3、DM1.4.11のReaderは据え置き。

## 原因と取得範囲

前回の軽量化では、`canRetainInsightView` が現在document開始以降の確認時刻だけを採用していた。開き直す前の表示用データが端末に残っていても、初期表示には使われず通信待ちになった。同一documentでの確認済みviewと、前回表示しただけのcopyを分けて扱う必要があった。

| 画面 | 修正前の通常起動 | 今回の動作 |
| --- | --- | --- |
| スキ | summaryと表示100件を確認。全スキ本文の取得ループは無い | 前回の最大100件・ページ・検索/日付/対応条件を先に表示。同じページ100件を裏で確認 |
| コメント | 最初の50件のあと500件ずつ全ページを確認 | 前回の先頭最大500件を先に表示。通常は最初の500件、過去分は必要時に取得。対応状態別は100件単位 |
| DM | summary/相手一覧の確認、選択相手の500件ずつ全ページ取得。定期確認2.5秒 | 前回の相手/表示最大500件を先に表示。冷起動で最新1ページ、過去は明示ページ操作。定期確認60秒、保存通知/明示更新は即時 |
| 本人通知 | 表示100件とrecentを確認。前回documentのboardを初期表示しない | 前回の表示最大100件・分類/日付/対応条件・ページを先に表示。現在ページとrecentの確認は維持 |
| フォロー比較 | 保存先の表示ページ50件を確認 | 前回表示と条件を先に表示。同じページを確認 |
| お気に入り | お気に入りとグループを確認 | 前回表示最大100件と条件を先に表示。既存の2取得を維持。バックエンドの全お気に入り返却は今回変更しない |
| マガジン | 保存済みのマガジンJSONを確認 | 前回の最大100誌・件数・条件と開いた記事検索最大100件を先に表示。復元だけでnote記事検索を再巡回しない |

summaryには別途、集計・件数と最大1,000件の記事カタログの取得がある。DB内部の集計が履歴全体を参照することと、全本文をブラウザーへ転送することは別。今回はDB/RPC/Edgeを変更していない。コメントのnote側保存元確認は別経路として従来通り残る。全コメントのテキスト検索は保存先APIに検索機能がないため全ページを確認し、検索中・暫定結果・失敗を明記する。

## 表示用コピーの扱い

`src/insight-saved-view.ts` は本人と現在の認証tokenの組に結びついた表示用コピーを扱う。認証情報そのものはcopyに保存せず、scopeは同期SHA-256で識別する。既存の端末保存/容量超過対応を使い、保存失敗は最新表示を止めない。

- 保存分には「前回表示分」「最新確認中」と本当に確認できた日時を表示する。copyを読む、条件を変える、操作を押すだけでは確認日時を進めない。
- 確認済み0件も有効な表示として保存し、以前の非0件を復活させない。
- 成功した現在の応答でだけ差し替える。同件数でも本文編集、削除、対応状態、★の変更を確認する。件数だけの一致で最新確認を省略しない。
- 本人/token変更、ログアウト、認証拒否、遅い旧scopeの応答を分離する。一時的な通信失敗では前回表示と失敗案内を保持する。
- 認証scopeが結びついていない従来のcopyは新しい即時表示形式へ自動移行しない。更新後の最初の成功した表示ページ確認で新形式を作り、次の開き直しから即表示する。保存済み履歴を削除する移行ではない。

同documentのfresh判定は変更していない。前回表示のcopyは「現在確認済み」の根拠にはしない。

## 検証と公開

機能ごとにコミットし、共通テスト調整とrelease/CI/docsはsupportコミットに分ける。CIに保存ページ/本人境界/限定取得の回帰群を追加する。型検査、build、維持中のPages workflow検証群、実際のbuild ESMの起動、公開ファイルのbyte/SHA一致を確認する。

公開の確認対象はroot/index、release manifest、deploy-version、Service Workerとbuild内の全asset。GitHub Actions/Pagesの成功と、各公開応答の完全byte/SHA一致を確認してから完了とする。元のAndroid端末での実操作、実際の通信料請求、端末での起動秒数は未測定。データ全件を先読みする形には戻さず、必要なページの確認を続ける。
