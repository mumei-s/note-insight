# 購入記事紹介の専用版 2.8.2

配布先は `public/note-profile-card-paster-purchased.user.js`。購入記事紹介だけを表示する独立したインストールIDと保存領域を持つ。

- 起動時からデータ選択・画像貼付/再開・通知カード貼付/再開・一時停止・停止・通知カードのみ削除・今回分全削除を表示する。操作を2列に収め、パネルの操作段数は維持。
- ハロウィン、スキ履歴、プロフィール、URL/タグ入力などの作成機能はバンドルしない。
- 通常サムネと無料公開部分の要約を並べる2.8.0の描画・入力検証・note正規アップロード処理を再利用。
- 旧総合版が同時に有効な場合も、旧パネルとランチャーを専用版の表示中は非表示にして重なりを防止。旧ツールのデータや本文は削除しない。
- 途中記録は専用領域へ保存。旧2.8.0の購入記事紹介の記録だけは、記事IDが一致した場合に移行して再開できる。
- 元の極薄ツールとその更新先は維持。新しい専用版を使う場合は旧2.8.0を拡張機能側で停止できる。
- note編集画面の外では何も起動せず、起動時の通信・自動貼付は行わない。

## 2.8.2 の通知カードと速度

- 画像後50ms、通知カードは開始から600ms以上、10件ごと2500msの待機を、既存の極薄ツールのソースからビルド時に取り込む。毎カードの処理時間を差し引き、固定待機を重ねない。
- 画像は品質95のJPEGで出力し、アップロード量を削減。サムネ全体、紹介文と配置は同じ。
- 画像の完成後、本文の位置をタップして③で正規noteカードを作成する。本文途中の挿入も既存の正規カード処理を再利用し、画像キャプションを分割しない。
- カードの確定・保存後に次へ進む。途中再開は記録済みの最後のカード直後から。変換結果が未確定な同一セッションでは再送しない。
- 「通知カードだけ一括削除」は記録したカードと、位置が一致する未記録の変換結果だけを削除。元からあるカードや後から手動で追加した同じURLのカード、画像、本文は保持する。
- 「今回分を全削除」は紹介画像・今回の通知カード・区切り線をまとめて削除する。
