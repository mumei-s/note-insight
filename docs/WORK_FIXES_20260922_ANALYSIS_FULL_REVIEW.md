# 2026-09-22 INSIGHT分析・全体点検

ユーザーの添付3画面と追加指示「全体の不具合確認修正も」を受けた修正。本体2026.09.22.9、Dashboard同期1.4.7。本人通知3.6.5、DM同期1.4.5は継続。ブラウザ本体のDM表示は今回修正している。

## 確認した原因と修正

- 本人通知分析：全通知の本文・metaをEdge側へ取り寄せ、行ごとに日時フォーマッタを作成していた。さらにrevision更新で画面を再マウントし、取得結果を捨てていた。認証済みの保存先だけをSQL RPCで集計し、必要な結果と日別件数を返す。クライアントは同時要求を共有、アカウント別に30秒キャッシュ、更新中も前回結果を保持する。30秒のタイムアウトと再試行を表示。
- 実データ確認時、本人通知は17,668件で9月22日まで保存済み。既存ルールで公開重複・誤捕捉を除外した11,454件を約243msで集計できた。これはDB内の実測であり、端末通信を含む表示時間ではない。
- 公式Dashboard：最新保存は9月9日、日別系列は0日だった。通常訪問では処理が終了しパネルを削除していた。またcoreのDOMContentLoaded依存、wrapperとcoreの二重コード交換があった。起動済みDOMにも対応し、コード交換をwrapper一か所に限定。連携済みの公式画面への通常訪問でも読込・保存を実行し、パネルを表示。別のnoteページには表示しない。
- 公式パネル：読込記事件数・日別PV日数・保存中・保存結果を表示。サーバーがsnapshotを確認した後だけ完了にする。日別0日は「日別グラフを開いて再読込」と明記。直接連携時だけINSIGHTへ戻る。
- 公式値：別タブへの自動切替と全期間へのフォールバックを廃止し、現在選択した公式期間を読む。ページで実際に観測した公式APIと埋込JSONを取得元とする。総計の未取得と0を区別し、記事の合計を公式総計に代用しない。保存時点比較も期間種別・開始・終了の一致を条件にした。
- 日別PV：指標名付きの座標系列、日付と値のペア、JST timestamp等を追加。記事別・流入別・月別値を全体の日別実績へ混ぜない。後日の公式訂正値を優先し、欠損と0を保持。平均は取得済み日だけを使う。前週比は比較可能な日数が揃った時だけ表示。
- 通知の点灯：通知コンポーネントが別タブのactiveクラスをアンマウント時に戻していた。DOMの選択状態書換えを撤去し、Reactのタブ状態に統一。通知→記事・全カテゴリ・履歴の戻る/進むを確認。
- TOP：分析カードの下に更新リンクを再生成しない。更新入口は分析内部の設定パネルに残す。通知スイッチは「🔔パネル ON/OFF」。同じ内容のDOM書換えを避け、静止中にMutationObserver更新が繰り返される問題を修正。
- グラフ：公式の線グラフと棒グラフを拡大・高コントラスト化。曜日・14日通知推移にタップできる柱グラフ、通知×PVに数値軸付き散布図。円グラフ・本人通知なしの独立HTMLも装飾を更新。割合やデータを誇張しない。ダッシュボード更新ボタンは縦横とも中央揃え。
- 購入注意：通知インストールとDashboard設定で、Safari版Tampermonkeyの購入料金がINSIGHTとは別にかかることを購入リンクより前に表示。Userscriptsの無料選択肢とストアの価格確認リンクを併記。金額は固定表示しない。確認元： https://apps.apple.com/app/tampermonkey/id6738342400 、 https://apps.apple.com/app/userscripts/id1463298887 （2026-09-22）。

## 検証と権限

- CIの全体回帰テスト219件（従来テストの移行を含む）とTypeScript/Viteビルド、現行userscript等16ファイルの構文確認。
- 対象：認証/ストレージ復旧、アカウント分離、通知分類・保存と再開、DM会話分離・過去/差分読込、フォロー相互比較・減・取得順、お気に入り、各カテゴリ移動、戻る/進む、Dashboard設定と値の取扱い。
- 新RPCはPGliteで実SQLを実行し、ノイズ除外、重複排除、7日/前7日比較、日本時間、他アカウント除外、実行権限を検証。旧JavaScript集計を呼ぶテストはSQLの挙動テストへ移行した。
- RPCはSECURITY INVOKER。PUBLIC/anon/authenticatedにはEXECUTEを付与せずservice_roleだけが呼ぶ。Edgeは既存の独自セッション認証を維持し、リクエスト本文の会員IDを採用しない。既存設定どおりverify_jwt=falseで、独自認証を省略していない。
- 関数配備：insight-notification-analysis-summary v6、insight-dashboard-data v10。DB/Edgeは配備済み。配布ソースの照合とPages公開確認は公開後に追記。
- 開始時main fca9e9952b2306f05181b6050d450100f734cacf。その後のmain 3586621f8247b965cf4d1f1c516f4be7723f9b09に含まれる他機能2ファイルの更新は保持して公開する。
