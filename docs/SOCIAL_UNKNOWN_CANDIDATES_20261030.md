# 2026-10-30 フォロワー「不明」候補の照合修正

- 最新の1,000人と過去の保存人物を重複排除して参照する。過去の1,000人は現在の末尾1,000人ではなく、保存開始の古い1,000人である。
- 人数だけの減少イベントには、**同じ同期実行**で現在の1,000人枠から外れた人物を先頭候補に表示する。検索はユーザー本人のscope、run ID、direction、event_type、人数0の観測に限定する。
- その後の本人関係の肯定証拠があれば候補から除く。候補をフォロー解除確定としない。既存の保存履歴・不明人数・確認済み減少は書き換えない。
- 同じ同期に候補がない場合には、以前の保存人物と関係確認候補を継続使用する。
- フロントの未確認調査では「枠外候補」と「実際の減少者」を区別して表示する。
- noteの認証を要する本人の解除確認は別。GitHub Pages側からnoteログインCookieを使ってプロフィールを監視できると主張しない。
