## 修正（Dashboard 1.5.2、サーバーFUNCTION_VERSION 10）

- 読取前に `sync-status` でDashboard用途の有効トークンとnoteアカウントを照合。失効時はパネルを操作せず「連携して読み込む」を表示。失効トークンを端末から外し、自動再読取を抑止。
- パネルを一斉にクリックする方式を廃止。表示の安定と進行中の通信を待ち、１つ開くたびに内容を蓄積。排他アコーディオン・遅い入れ子・div内の見出しに付く開くボタンに対応。
- 記事／マガジン／メンバーシップの内容タブも逐次取得。期間タブ・メニュー・購入・送信操作を除外。途中で画面や期間が変わった場合は中止。
- 日付と指標を持つ日別表も取得。0件を保持し、欠損は0として補完しない。日別未取得は従来どおり「部分保存」とし、同期完了／自動復帰にしない。
- 正常に取得した直後の公式APIを重複再送しない。通信捕捉に失敗した場合は実際に観測済みのURLだけ再取得。
- 通常noteページではcoreのfetch/XHRフックを開始せず、SPAでDashboardに移った場合はマウント要求から開始。
- 保存後、同じ本人・確定済みsnapshot IDのDBを読み返す。実際の記事行数、日別件数、公式合計が一致した場合だけ保存確認／同期完了を表示。保存照合は読み取り専用で、別の本人の記録や未確定記録は返さない。
- wrapperとcoreの版数を1.5.2、実際の@requireを `?v=152` へ更新。通知・DM・カードツールは変更しない。本体バージョンは据え置きでDashboard更新を案内。
