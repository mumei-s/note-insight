# 1人・本数なしの記事追加通知 — 本人通知3.6.14

## 実機報告と原因

添付1000015365.jpgでは、同じ人物が各マガジンに「記事を追加しました」と表示された通知が残っていた。最新main `492103467c26e837468576fd0374ab2dc347649a` のフィルター4.1.3は記事追加の本数（○本）を必須にしていたため、本数を表示しない単独通知が対象外になっていた。1人・最後の1件を意図的に残す仕様ではない。

## 変更範囲

- フィルター4.1.4：マガジン名の後の「に記事を追加しました」「に新しい記事を追加しました」を判定に追加。
- 登録人物が先頭であること、アカウント別設定、グループON/OFF、通知パネルの範囲は維持。
- 引用された記事タイトル内の文言を通知動作と誤認しないよう、直後の閉じ引用符を除外。
- Reader、保存、分類、DM、ダッシュボード、パネル表示には変更なし。
- 配布版：本人通知3.6.14、filter @require `?v=414`、本体2026.09.28.1。

## 検証

- 新規5件は修正前に失敗し、修正後に成功。
- 実Reader併用・GM新旧形式で、単独人物の通知1件／3件、改行、省略された人物名、複数マガジン、ON/OFF、🔔再表示を検証。
- スキ・返信・自分の記事追加・未登録人物・記事タイトル中の同じ文言を非表示にしないことを検証。
- フィルターの検証20件成功。公開時は既存のビルド・全回帰ゲートも実行する。
- 利用者の実端末上で新版を動かした結果は未確認。画像の文言を用いたDOM動作検証と区別する。
