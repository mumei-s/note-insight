# INSIGHT実画面紹介：25秒版

参加者募集・メンバーシップ内の機能紹介向けに、既存の不具合報告スクリーンショットを再編集。82秒の説明中心の動画を、25秒・17カットへ短縮した。スキ履歴、コメントの絞り込み、フォローの人物一覧、本人通知、保存・フィルター、note上のDM読み込み、記事、記事別ランキング、構成比・日別推移・本人通知分析を順に紹介する。終端はINSIGHTロゴ。動画内のURLと参加案内を削除した。

掲載画面は保存時点の実画面であり、最新UIの操作録画ではない。名前・ID・アイコン・記事タイトル・入力済み検索語・DM/通知本文は、描画・トランジション前に不可逆の切り取りまたは不透明な塗りつぶしで除外。売上金額を含む領域も使用していない。空のランキングやエラー画面は使わず、記事別の実データ表と実グラフを使用した。スキ/コメントの実際の明細行は添付に見つからなかったため、その画面は見出し・保存件数・絞り込みを紹介する。架空の明細や集計値は追加していない。

サムネイルは中央安全領域に収めた既存1200×1200画像を継続。ページ、動画、OG画像にquick-20261004-4を設定。INSIGHT本体の機能・認証・userscriptには変更なし。

検証：全17カットの画像と切替直後・終端を目視確認。H.264/AAC、1280×720、24fps、25秒、faststart。紹介ページの6チャプターは実際の映像開始秒に合わせる。
