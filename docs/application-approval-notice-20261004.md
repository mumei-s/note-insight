# 申請者本人の承認通知

Appが実際に使うAccessPortalV6の承認待ち画面で15秒ごと、および画面に戻った時に申請状況を確認する。本人の申請トークンを使い、申請ID・note ID・現在のトークンが一致する応答だけを採用する。承認を検知したら画面内で通知し、本人確認の画面へ進む。

端末通知を既に許可している場合は同じ申請について一度だけ端末通知も表示する。画面を完全に閉じている場合は、次に開いた時に保存済み申請から承認状態を復元する。Web Pushは追加していない。

申請を受け取るOWNER側の既存通知は、OWNER認証済み画面だけで表示する。公開中のowner-pending処理とis_owner_tokenを読み取りで確認し、空・無効トークンは拒否された。一般参加者へ申請一覧を公開しない。

検証: 本人の自動承認表示、別申請の抑止、アカウント切替後の遅延応答の破棄、再表示、重複通知の抑止、監視終了時のタイマー解除、OWNER以外への通知抑止。

現在の参加画面への組み込みをAppのimportからテスト対象を選んで検証する。旧AccessPortalV5への追加は戻した。本人確認済みの再参加者は承認通知後、既存の再開処理を継続し、画面遷移後も短い通知を表示する。
