# Dashboard 1.6.7

公式ダッシュボードのパネルを「読み込み／停止」「履歴」「OFF」に整理。通常訪問・再訪・公式通信の受信では読み取りを開始しない。既存の自動設定値にも依存しない。連携直後の明示的な読み込み依頼のみ一度実行する。

取得済みデータは、停止・別ページ・通知シート・バックグラウンドでも本人用の保存キューから保存・件数照合を続ける。完全なページ移動の前には保存待ちデータを永続化し、次のnote訪問で本人を確認して再試行する。画面を完全に閉じた後のJavaScript実行は保証できないため、未完了分を破棄しない。保存確認だけ失敗した場合は同じsnapshotIdを照合し直す。接続トークンはキューにコピーしない。

公式パネル・日別グラフ・記事の追加ページを開いて読む。待機は初期表示の安定を確認し、各切替後は通信・公式ローダー・値の変化が止まった時点で短縮する。その回に取得した指標は重複して開かない。次の明示読み込みでは指標を確認し直し、同じ値の再保存をハッシュで抑止する。

途中保存は記事の全件読込と区別し、既存の完全な一覧を少ない途中件数で置き換えない。日別値の保存履歴は維持する。
