# 分析入口と同期パネルの導線修正

- 分析カード・選択内容の汎用 dashboard クラスを除去。ページ全体用左右余白と70px下余白がカードへ混入し、上段の高さとタイトル折返しを壊していた。専用クラスで4つの独立した入口を保つ。
- カードを通常時98px・選択時64pxに詰め、⚙は44pxの独立した列として分離。重なる絶対位置を廃止。
- 一覧の浮上・収まり、光の通過ときらめきを追加。装飾はpointer-events:none、画面外・非表示・動きを減らす設定では停止。
- 設定のON/OFFはnote上の同期パネルだと明示。本人通知を開いた戻り先でも「INSIGHTプロを開く」からdashboardパネルへ移る。ONは連携・初回取込の完了を意味しない。

検証: 分析メニュー・設定・同期ON/OFFのReact/DOM/実スクリプトテスト、TypeScript/Viteビルド、差分空白確認。認証・本人履歴・数値計算・同期ツール本体に変更なし。
