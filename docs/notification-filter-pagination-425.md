- 混在する通知行をDOM順へ並べ、本当の末尾を選ぶ。
- 公式sentinelを含むULを、短い場合も公式scroll rootとして選ぶ。旧表示に対しては非表示前のscroll枠を保持する。
- 末尾の元の通知ノード・内部寸法を保持し、内容と操作はopacity/aria-hidden/inertで隠す。1pxへの縮小と内部clipを廃止する。
- 「続きへ」は末尾と公式sentinelの実座標へ進む。後方の大きいfooterへ通り越さない。
