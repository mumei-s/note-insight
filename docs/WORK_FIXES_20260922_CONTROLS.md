## 確認した原因と変更

### 通知

- 旧Controlsは `touchstart` / `touchend` / `pointerdown` などで `preventDefault()` し、処理自体は `click` のみで実行していた。タップからclickが作られない端末では、全ボタンが押せなくなる。開始・終了イベントは伝播だけを止め、既定動作の取消はclickだけに変更した。
- タッチ、マウス、キーボードで同じボタン処理を利用。noteの背面へクリックを流さない。
- Controlsのmountが毎回styleとボタンの文字を書き換え、MutationObserverで次のmountを呼び、アカウント通信を繰り返す経路があった。styleは1回、同じ文字は再描画しない。自分の状態表示の変化を監視対象から外した。
- 設定／INSIGHT／停止の操作を、毎回のcurrent_user通信待ちから切り離した。フィルターの本人確認は維持し、8秒タイムアウトと同時要求の合流を追加。
- 0件を「✓保存」と表示しない。「新着なし・今回の追加保存0件」「読込N・保存確認N件」「途中保存・続き読込」「再試行」を区別する。
- APIから取得した件数を収集中にも増やす。保存件数はサーバーが署名を確認した分だけ。最大300件、古い順の保存、未送信journal、続き読み、保存済み板の即表示は維持。
- 4列パネルを下部固定。42pxのタップ領域＋進捗1行にまとめた。
- 本番では本人通知の保存記録を確認。調査時の直近通知には旧3.5.7のmetadataが残っていた。これは保存時の版であり、現在端末に入っている版を直接証明しない。公開後は通知3.6.1の導入版と照合する。

### DM

- 調査時点の本番は相手21ルーム、本文0件。人数を取得できたことを本文取得成功として表示しない。
- 旧フレームは左へ12,000px離した画面外配置。可視領域を基準に描画する会話UIが表示されない可能性があったため、画面内の不可視・クリック不可レイヤーへ変更。利用者のnote画面は移動させない。
- 親Readerから会話フレームのfetch/XHRも監視できるようにし、会話の構造化JSONも取得する。`room.id`を子メッセージへ引き継ぐ。`last_message`やpreviewを全本文として取り込まない。
- メッセージを表すDOM候補を補強。構造化本文がある場合はそちらを優先する。
- 未ログインや別ページへのリダイレクトを区別。フレームは停止時に破棄。構造化本文が保存できても、過去分の終端を確認できなければ完了とはしない。
- note DM画面に本文読込・保存確認・相手数と停止／続き読込を表示。
- 各相手の読取結果（版、件数、完了、エラー）を、既存threadの `meta.reader_status` に保存。本文・認証情報は診断出力に追加しない。INSIGHT側も本文未保存と相手別エラーを表示する。
- ingest/feedは既存のDM専用認証と本人スコープを維持。新テーブル、RLS変更、通知認証との共用はない。
- **実DMの本文取得成功は未確認。** 検証ブラウザはnote未ログインで `/messages/rooms` からトップに戻った。認証の回避はしていない。

### フォロワー・フォロー

- 最新1,000人／過去から1,000人の切替を「人物一覧」に加え「増減履歴」「解除・関係終了の調査」に適用。
- 選択した1,000人を先に確定し、その中の名前検索・増減・日付で絞る。検索のたびに1,000人の対象が変わる問題も防止。
- 過去は初回保存が古い1,000人。記録開始前の人物を復元したものではない。
- 「全履歴」も残し、現在の枠外の人物や人物不明の総数増減を確認できる。
- 長いURLを避けるため人物キーを80人ずつ照合、最大3要求を並行。結果を全体の日時順に並べ直してページ分けする。最新枠からの消失を解除と断定しない仕様は維持。

### グラフ

- 円は12pxの側面、明暗、内側のくぼみと影。前面の角度は件数比を維持。凡例選択で件数・割合を中央表示し、0件でNaNを出さない。
- 棒は上面の光と下面の厚み。数値を表す前面の長さは変えない。
- 線は陰影とハイライト、選択日ガイドを追加。日付／指標／単位／欠損の区別は維持。14pxの点選択領域とキーボード操作を追加。
- グラフの詳細表示がデスクトップで別の場所に浮くCSSも修正。

## ブラウザ対応と確認範囲

- Edge / Chrome / Firefox / Safariで使う共通のDOM・Storage・SVG実装を維持。UAで特定ブラウザを除外する分岐は追加していない。
- GM.getValue / GM.setValueの新式、GM_getValue / GM_setValueの旧式をそれぞれ操作テスト。
- タッチイベントを取消せずclickへ繋ぐこと、クリックがnoteへ抜けないこと、キーボード由来clickも同じ経路になることを検証。
- Safariのスクリプト環境、Android Edge / Firefox、ChromeやYahoo!での既存インストール・対応ブラウザへの案内を保持。INSIGHT閲覧とnote上でスクリプトを実行できる環境は区別する。
- Android実機・Safari / Firefox / Edge実機の成功を確認したという意味ではない。ローカルプレビューは検証ブラウザから開けなかった。円の描画はコード由来SVGを画像化して確認した。
