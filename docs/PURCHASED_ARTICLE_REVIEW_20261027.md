# 購入記事の紹介（2.8.0）

購入した記事の選択済み一覧を、番号やプロフィールのない紹介画像として貼り付ける専用モードを追加。

- サムネイル全体を縦横比のまま保持。860pxの画像内で横420px、本文幅620pxなら約303px相当。
- 右側はクリエイター名と、無料公開部分を確認して作った短い要約。22pxの本文文字（本文幅620pxでは約16px相当）。長い紹介文も切らずに画像の高さを調整。
- 画像全体に対象記事のリンクと名前キャプションを付与。各項目の間にnote標準の区切り線を追加。
- 入力順を維持。番号・10人ごとの見出し・プロフィール・末尾の別記事は追加しない。
- 読込と貼付を分離。読込後に本文の位置を選び、「紹介を貼り付け／再開」で開始。
- 一時停止時は完成済みの1件を記録・保存してから停止。再開時は画像の順序と所有記録を照合。別の作成記録や不明な画像がある場合は停止する。
- 新しいパネル項目は初期状態で折り畳み。INSIGHT側のコード・データ・通信は変更しない。

## データ形式

`format: mumei-note-purchase-review-v1` と `items` を持つJSONを読み込む。各項目は `urlname`, `key`, `url`, `creator`, `displayCreator`, `title`, `summary`, `thumbUrl`, `sourceScope: public-free-section`, `sourceCheckedAt` が必須。

紹介対象一覧と紹介文は利用者側のJSONと拡張機能の保存領域に置き、汎用スクリプトには埋め込まない。スクリプトは紹介文を自動推測せず、指定した記事画像のみを取得する。
